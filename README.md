# Decoin

A repo for trading strategy research of crypto currency.

## Downdloads Historial Data

### Binance

- URL for spot trades:

<https://data.binance.vision/data/{type}/daily/trades/{Symbol}/{Symbol}-trades-{YYYY-MM-DD}.zip>

- URL for spot klines:

<https://data.binance.vision/data/{type}/daily/klines/{Symbol}/{freq}/{Symbol}-{freq}-{YYYY-MM-DD}.zip>

- URL for futures trades:

<https://data.binance.vision/data/{type}/daily/trades/{Symbol}/{Symbol}-trades-{YYYY-MM-DD}.zip>

- URL for futures klines:

<https://data.binance.vision/data/{type}/daily/klines/{Symbol}/{freq}/{Symbol}-{freq}-{YYYY-MM-DD}.zip>

where `type=futures/um` or `type=futures/cm`
